# Management Action Control Specification

## Controls

All management action controls are defined but remain blank or at default values.

| Control | Type | Default | Editable |
|---|---|---|---|
| Selected Action | dropdown | empty | Yes |
| Selected Scenario | dropdown | empty | Yes |
| Review Outcome | dropdown | Pending | Yes |
| Management Comment | text area | empty | Yes |
| Conditions Imposed | text area | empty | Yes |
| Reviewer Role | dropdown | empty | Yes |
| Approval Reference | text | empty | Yes |
| Confirmation Checkbox | boolean | False | Yes |
| Defer Reason | text area | empty | Yes |
| Reject Reason | text area | empty | Yes |
| Request Evidence Type | dropdown | empty | Yes |
| Route to Monitoring | boolean | False | Yes |
| Route to Non-Quantitative | boolean | False | Yes |

## Governance

- No action is preselected.
- No scenario is preselected.
- Review outcome defaults to Pending.
- All controls require explicit management interaction before submission.
- Approval reference remains blank until an approval workflow is triggered.
