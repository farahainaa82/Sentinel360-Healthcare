# Step 3B KPI Pressure Summary

## Headline KPIs
1. Staffing Level
2. Staff Absenteeism Rate
3. Bed Occupancy Rate
4. Average Patient Waiting Time
5. Patient Complaint Rate
6. Patient Satisfaction Score

## Display Rules
- Latest governed value displayed as-is
- threshold_status shown directly from dataset
- departments_red counts Red/Critical threshold statuses
- trend and watch_flag displayed if present
- confidence_status displayed if present

## Constraints
- No recalculation of KPI values
- No averaging of incompatible units
- Drill-down button disabled until Step 3C
