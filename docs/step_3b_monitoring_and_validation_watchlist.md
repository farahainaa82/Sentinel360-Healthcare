# Step 3B Monitoring and Validation Watchlist

## Monitoring Watchlist
- Packages with readiness_status = Monitoring Only
- Fields: Department, KPI, Current Condition, Watch Status, Escalation Trigger, Reassessment Condition

## Validation Watchlist
- Packages requiring: assumption validation, baseline validation, financial input, stakeholder validation, evidence completion, lineage completion
- Fields: Department, KPI, Current Condition, Required Validation, Responsible Role, Primary Queue, Urgency

## Constraints
- Triggers and requirements remain visible
- No automatic reassessment performed
