# Step 3B Decision Readiness Display

## Readiness Categories
1. Ready for Integrated Management Review
2. Ready with Conditions
3. Monitoring Only
4. Requires Assumption Validation
5. Non-Quantitative

## Visualisation
- Horizontal bar chart of counts
- Table with counts and percentages

## Blocking Summary
- blocking_conditions: count of Requires/Conditional statuses
- pending_confirmations: count of non-empty evidence warnings
- stakeholder_validation, financial_input, scenario_validation: tracked where data exists

## Constraints
- No single opaque aggregate score
- Conditions remain visible
