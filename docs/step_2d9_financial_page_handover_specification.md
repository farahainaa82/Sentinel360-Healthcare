# Financial Impact Page Handover Specification

## Fields

- Cost completeness status
- Cost components
- Benefit components
- Net financial impact
- Lower, Central, Upper estimates
- Financial confidence
- Missing input warning
- Budget information requirement
- Affordability status
- ROI status
- Payback status
- Double-counting status
- Evidence and uncertainty references

## Constraints

- Do not display guaranteed savings.
- Do not show blocked ROI or payback as valid values.
- Financial estimates include uncertainty and should be treated as ranges.
- Missing inputs generate warnings, not zero values.
